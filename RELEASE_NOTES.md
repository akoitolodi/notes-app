## What's New in Notes by Bai v2.0.0

### 1. Dedicated Announcements Command Panel
- **Live Announcements Card on Home**: Shows unread badge, 1-tap `Sync`, and pinned/latest teacher posts right at the top of Folders Home.
- **Full Announcements Panel**: Filter by **All / Unread / Pinned** + per-subject chips + search, **Pin** important posts (Google Chat links, syllabus rules, room changes), clickable auto-linked URLs, **1-tap `+ Add Date to Calendar`** for dates mentioned inside posts, **`Save Note`**, inline Canvas `.atom` RSS setup, and **`+ Paste`** for Messenger/GC posts.

### 2. Magic Blank-Note Auto-Detection ("Smart Strip")
- Docked cleanly above the editor toolbar, completely hidden on plain text, toggleable via **`⚡ Smart`**, and **strictly disabled** inside Zero-AI `Passwords & Keys` Vault notes.
- **1-Tap `▶ Run` for All Languages**: Automatically recognizes raw typed code even *without* ```` ``` ```` backticks (JS, Python, HTML/CSS, C/C++, Java, C#, SQL, Go, Rust, PHP) — runs JS (with infinite-loop protection) & HTML 100% offline, and Python/C++/Java/SQL via live sandbox + AI fallback, with 1-tap **`+ Insert Output`** and **`Wrap Code`**.
- **100% Offline Math, Science & Student Solvers**: Arithmetic, percentages, linear & quadratic equations (`2x + 5 = 17`, `x^2 - 5x + 6 = 0`), variable scratchpads, unit & base conversions (`37 C to F`, `255 to hex`, `0b10110 to dec`), 1-tap **2D Grapher** & **AI Steps**, **Chemistry** molar mass (`H2SO4`, `Ca(OH)2`), **Physics** SI solver (`F=ma`, Ohm's Law, `KE/PE`, kinematics), **Statistics** (`Avg`, `Med`, `Sum`, `SD`), **IPv4 CIDR Subnets**, **Color Swatches**, **Deadlines → Calendar**, **Offline Flashcards** from `Term: Definition` lines, **Error/Stack-Trace Debugging**, **Public Google Docs Import**, and **Filipino/Bisaya ↔ English** quick translate.

### 3. Phone-Friendly Templates & Mid-Note `+ Block` Overhaul
- **Visual 2-Column Template Gallery**: Clean, zero-filler starters with miniature layout previews across **Quick / School / Coding / Personal / Mine** tabs.
- **Mid-Note `+ Block` Inserter**: Drop a Checklist, 2-Col Table, JS/Python Code Block, Math Scratchpad, Callout, Flashcard Terms, or Class Header straight into any blank note.
- **Save as Personal Template**: Save your own note layouts (`•••` → **Save as Personal Template**) into your **`Mine`** tab (Dexie v8 + JSON Backup included).

> Includes all `v1.9.1` features (Native Android Text-to-Speech Study Commute Audio & Hands-Free Flashcards, Course Dashboard, Grades + What-If Simulator, CHED Attendance Guard, and Android Share/Open-With Course Module Import).
